Classic board games · Portfolio project

An early project, brought up to date.

This started as one of my earlier front-end development projects — a small online store built around ten classic board games.

The original idea still worked, so I kept it.

What has changed is how it has been put together, with clearer structure, better responsive behaviour, improved accessibility and a stronger visual system.

The cart still handles the real work: adding products, updating quantities, calculating VAT and delivery, and keeping the order state in the browser.

01 · The collection

Ten classic games.

Built around a simple idea

A simple idea, properly built.

The games are familiar. The point of the project is the interface behind them.

Product cards, cart actions, quantity controls, delivery options, VAT and order totals all work together as one small storefront.

This is not being presented as a full commercial e-commerce platform.

It is a portfolio project showing where the original build started, what still worked, and how I would approach the same project now.

02 · Continue exploring

One collection. One working cart.
